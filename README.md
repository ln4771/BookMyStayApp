# Book My Stay App

The objective of the Book My Stay App is to design and implement a Hotel Booking Management System using Core Java concepts. The system is built incrementally through multiple use cases to demonstrate how software systems evolve while applying programming fundamentals.

---

## UC1 : Application Entry & Welcome Message

Objective:
Create the entry point of the Hotel Booking application and display a welcome message.

Flow:
- Start the application
- Display welcome message for the user
- Show application name and version

Concepts Used:
Main Method, Console Output, Basic Java Program Structure

## UC2 : Basic Room Types & Static Availability

Goal:
Introduce object modeling through inheritance and abstraction before introducing data structures.

Flow:
- Start the application
- Create room objects for different room types
- Store availability using simple variables
- Display room details and availability

Concepts Used:
Abstract Class, Inheritance, Polymorphism, Encapsulation, Static Variables

## UC3 : Centralized Room Inventory Management

Goal:
Replace scattered availability variables with a centralized inventory system using HashMap.

Flow:
- Initialize inventory system
- Store room availability using HashMap
- Retrieve availability through controlled methods
- Display inventory state

Concepts Used:
HashMap, Encapsulation, Separation of Concerns, Inventory Management
